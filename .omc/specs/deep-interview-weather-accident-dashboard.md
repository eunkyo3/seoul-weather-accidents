## Goal
서울시 2007–2025년 중상·사망 교통사고 데이터(약 20만 건)를 기반으로, **날씨(계절·비·눈)가 교통사고에 미치는 영향**을 보여주는 **인터랙티브 웹 대시보드(Next.js)**를 만든다. 필수 분석은 4가지: ① 계절·월별 사고 추이, ② 기상상태별 사고율 비교(기상청 월별 데이터로 노출 보정 포함), ③ 서울 25개 자치구 지도 시각화, ④ 날씨×주야/도로형태/차종/연령대 심층 크로스 분석. 발표 시연은 로컬 Docker Compose로 실행하며, **보이는 화면의 완성도가 최우선 평가 기준**이다.

- 판정(지지/부분 지지/기각)은 사람이 임의로 쓰지 않고 **파이프라인이 결정적으로 산출**한다 (판정 규칙은 Phase 0에서 확정·명문화).

## Constraints
- 기술 스택: **React/Next.js** 프런트엔드 (사용자 명시 선택)
- 데이터 처리: Python(pandas)으로 엑셀 → 사전 집계 JSON 정적 파일 생성 (런타임 DB 불필요)
- 시연: **로컬 Docker Compose** (`docker compose up` 한 방으로 재현 가능해야 함)
- 일정: 한 달 이상 여유 — 4개 분석 전부 + 디자인 완성도 극대화 가능
- 데이터 제약: `발생년월`이 **월 단위** → 일별 날씨-사고 매칭 불가, 월 단위 결합만 가능
- 데이터 제약: 좌표 없음 → 점 지도 불가, `시군구` 기반 단계구분도(choropleth)만 가능
- 데이터 제약: 중상·사망사고만 포함 (경상 제외) — 화면·보고서에 명시 필요
- 외부 데이터: 기상청 기상자료개방포털(data.kma.go.kr) 서울(108 지점) 월별 통계 — 강수일수, 눈일수, 강수량, 평균기온. **로그인·API 키 없이 통계분석 코너 CSV 엔드포인트로 수집 가능함을 실측 검증 완료(2026-07)** — 강수일수·눈일수·평균기온 228개월 전량 수신 확인, 강수량만 수집 파라미터 재조정 필요
- 실시간 날씨(오늘의 위험도 위젯): Open-Meteo API(키·가입 불필요) — 실패 시 날씨 수동 선택 토글로 폴백
